# WiFi Connect

PWA para escanear etiquetas de routers, detectar datos Wi-Fi, generar códigos QR y gestionar redes temporales o guardadas de forma local.

**`Estilo.png` es la referencia visual oficial de WiFi Connect.** Las futuras modificaciones de interfaz deben tomarla como base salvo que se indique otro diseño.

- QR Wi-Fi para redes manuales y redes actuales.
- Captura con cámara y selección desde galería.
- OCR y parser ejecutados localmente en el dispositivo.
- Historial y credenciales guardados en almacenamiento local.
- Interfaz y recursos estáticos disponibles sin backend.
